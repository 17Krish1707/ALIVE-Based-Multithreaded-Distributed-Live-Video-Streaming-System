ALIVE Hybrid P2P-CDN Architecture Model
VTS (Virtual Tracker Server) allocates client streaming sessions dynamically to Peer-1, Peer-2, Edge-1, or CDN-1 based on node availability, active capacities, and network latency thresholds. Each client streaming session runs on dedicated concurrent Node.js Worker Threads with SHA-256 chunk validation.
